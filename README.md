# EAT&SIT

## Description

EAT&SIT — мобильное приложение для заказа еды с доставкой от ресторанов и кафе города. Рестораны отображаются на интерактивной карте, что позволяет пользователю легко найти ближайшие заведения. Приложение решает проблему поиска и заказа еды онлайн, предоставляя пользователям удобный способ выбрать блюда и оформить заказ. Весь процесс — от выбора ресторана до оплаты и отслеживания доставки — реализован в едином интерфейсе.

## Installation

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/Nastya404/tpmp-lab9
   ```
2. Перейти в директорию проекта:
   ```bash
   cd tpmp-lab9
   ```
3. Установить зависимости через CocoaPods:
   ```bash
   pod install
   ```
4. Открыть проект в Xcode:
   ```bash
   open EatAndSit.xcworkspace
   ```
5. Выбрать симулятор или подключённое iOS-устройство и нажать **Run (⌘R)**.

## Usage

После установки и запуска приложения:
 
1. **Регистрация / Вход** — создайте аккаунт или войдите в существующий.
2. **Выбор ресторана** — используйте карту или список для поиска ближайших заведений.
3. **Оформление заказа** — выберите блюда, добавьте их в корзину и укажите адрес доставки.
4. **Оплата** — выберите удобный способ оплаты и подтвердите заказ.
